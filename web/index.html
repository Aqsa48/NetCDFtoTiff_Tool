Built for regular grids

Supports 1D latitude/longitude axes and rectilinear 2D coordinates. Choose an index for each extra dimension, including time. Packed scale/offset and missing values are decoded.

Working with NetCDF4?

Use the Python package for NetCDF4/HDF5 or larger files. Curvilinear, projected, irregular, and dateline-crossing grids need regridding first.

pip install .
nc2tiff input.nc --list
nc2tiff input.nc output.tif \
  --variable rain --isel time=0
